# 🐦 Bird Hunter Game

Um jogo simples e interativo feito com **HTML, CSS e JavaScript puro**, onde o jogador precisa clicar nos pássaros antes que o tempo acabe.

Acesso o jogo: https://birdgame.carlos0101.xyz/

O jogo foi desenvolvido com foco em:
- Manipulação de DOM
- Animações com `requestAnimationFrame`
- Eventos
- Responsividade (desktop e mobile)
- Estrutura modular com ES Modules

---

## 🎮 Como Funciona

- O jogador tem um tempo limite.
- Pássaros aparecem aleatoriamente na tela.
- Cada tipo de pássaro vale uma pontuação diferente:
  - 🐦 Small → +2 pontos
  - 🐤 Medium → +1 ponto
  - 🦅 Large → +0.5 ponto
- Ao clicar, uma animação de explosão é exibida.
- Quando o tempo acaba, o jogo finaliza e mostra o score final.
